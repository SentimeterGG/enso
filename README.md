## ENSO
A rythm game where you draw shapes in time with the music.

## Gameplay
There will be shapes that approaches the circle. You will have to draw each stroke of the shape to the beat.

## Installation
Download from the latest release. Right now, it is only available for Windows and Android (MacOS and native Linux support coming soon).
The game already has an auto-update system so you shouldn't worry about coming here often.
